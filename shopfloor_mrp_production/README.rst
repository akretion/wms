MRP Production
~~~~~~~~~~~~~~

This scenario let you produce Manufacturing Orders with shopfloor.

It's a two steps process:
- scan the barcode of the MO
- scan the destination location

It will act like the "mark as done" and force the all quantities to be done.

Usage
=====

Create a shopfloor menu
~~~~~~~~~~~~~~~~~~~~~~~

* Go to "Shopfloor -> Menus"
* Create a menu with "MRP Production" scenario and select a manufacturing operation

Known issues / Roadmap
======================

* allow to confirm without scanning a barcode location
* allow to scan multiple barcodes to increase quantities
* allow backorder creation
* support serial numbers and batch
